# v1.7.0 (2026-11-03)

## Added

- Structured tool-result compressor (default `smart`): trailing-whitespace
  normalization, build-noise stripping (`\r` overwrite frames, progress
  percentage lines), duplicate-run folding (`[folded N identical lines]`,
  first and last lines kept), and over-budget head/tail summaries
  (first 50 + omission count + last 20 lines). Paths, hashes, error codes,
  and stack frames are never folded (whitelist).
- Settings: `webcodeGateway.compression.toolResult` (off|trim|smart,
  default smart) and `webcodeGateway.compression.maxResultChars` (default
  12000, clamped to 1000–524288), effective immediately from the VS Code
  settings page.
- Feedback audit contract: compressed results carry `compressed: true`
  with applied rules and before/after character counts, visible to the
  model.
