# v1.4.1 (2026-10-24)

## Fixes

- Upgrade `zod` to 4.6.7 to close advisory 1243066, which has no patched v3
  release. The MCP SDK declares `^3.25 || ^4.0` and `zod-to-json-schema`
  declares `^3.25.28 || ^4`, so both accept the v4 line, and the workspace now
  resolves a single zod copy instead of keeping a nested v3 one.
- Raise the `body-parser` override floor to 1.20.9 to close advisory 1243073.
  Express resolves to 1.20.9 across the workspace.

## Engineering

- The release build script now resolves the Windows bsdtar explicitly. When
  run from a Git Bash environment, PATH could put Git's GNU tar first, which
  treats the drive letter in a `C:\...` path as a remote host and fails to
  package the browser extension.
