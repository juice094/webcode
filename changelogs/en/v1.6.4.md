# v1.6.4 (2026-11-03)

## Improved

- De-identify tool results and inserted text (closes the 1.6.3 gap): 1.6.3
  scrubbed only the injected prompts, while product naming in tool results
  and chat-inserted text slipped through — the root cause was that
  model-facing strings have no single chokepoint. This release clears the
  terminal receipt prefix, the schema-validation error, the list_tools /
  list_skills descriptions, the zh/en oversized-init notices, and the
  protocol-error reply (rejection notice and initialization example).
- Add regression gates: a gateway unit test scans every prompt template,
  every local tool description, and the tool-result source files; a bridge
  runtime test scans the inserted-text sources. Both assert that no
  model-facing surface names the product (allowlist limited to package
  specifiers, user-input trigger tokens, and internal identifiers), so this
  cannot silently drift back.
