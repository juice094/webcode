# v1.6.3 (2026-11-03)

## Improved

- Prompt de-identification: injected prompts no longer mention the product
  name (neutral "the gateway" phrasing everywhere); the bootstrap tool name
  changes from `webcode_init` to the neutral `initialize` (no longer derived
  from the brand slug); injected `# Available Tools` / `# Available Skills`
  context headers drop the product-name prefix; the built-in Skill virtual
  root moves from `.webcode/builtin-skills/...` to
  `.gateway/builtin-skills/...`.
- Rationale: injected content is visible to the web AI platform's server,
  and naming the tool bridge is useless information that hands risk control
  a zero-cost automation signal; this removes that attack surface.
- Also updated: identity mentions in tool descriptions, evals/unit-test
  assertions, and the affected user docs. The `/webcode` / `@webcode`
  trigger tokens are user input and stay unchanged.
