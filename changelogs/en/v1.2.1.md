# v1.2.1 (2026-10-20)

## Features

- Replaced the browser popup's single "auto-approve all tools" toggle with a three-level
  approval mode: Always Ask / Ask When Needed / Never Ask (matching Kimi Code's permission
  modes). Ask When Needed is the new default: routine tool calls run automatically while
  dangerous commands and sensitive files still force a confirmation modal. The legacy
  auto-approve toggle migrates to Never Ask. The mode persists per tab, and the
  "new session preset" panel controls the default for future sessions.

## Security

- File tools (read_file / write_file / edit_file / attach_file) now gate sensitive paths:
  accessing `.env` variants, SSH private keys, certificate/key files (.pem/.key/.ppk/.p12/.pfx/.kdbx),
  credential files (credentials, .npmrc, .pypirc, .netrc), and .ssh/.aws/.gnupg/.kube directories
  returns a requires-confirmation risk from the gateway preflight and forces a modal approval.
  Approval tokens are single-use with a two-minute TTL. Shell path commands (cat/cp/mv/rm)
  touching sensitive files trigger confirmation as well. Templates and public material such as
  `.env.example` and `*.pub` keys stay unaffected.
