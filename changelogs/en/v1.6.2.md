# v1.6.2 (2026-11-03)

## Improved

- Prompt restructure: the control-flow contract now leads the injected
  prompts (results arrive in the user's next reply, never fabricate results,
  batch only independent calls, writes stay serial), with duplicate rules
  merged; the identity naming section is removed since tool capability is
  fully described by the injected tool list; path and command guidance moves
  into a dedicated section with a new note on workspace root versus
  repository root.
- Repository docs are now English-first: READMEs and guides default to
  English (Chinese versions move to `_zh.md` names), index tables list
  English entries first, and the generated VS Code Marketplace README puts
  English before Chinese.
