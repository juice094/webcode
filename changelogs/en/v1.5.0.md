# v1.5.0 (2026-10-24)

## Features

- Detect platform-native tool syntax emitted by the model (DeepSeek DSML,
  Anthropic antml). When a reply contains such markers and no executable JSON
  call, the page now shows a notice instead of letting the turn fail silently
  with an unreadable block of text. Each message notifies at most once, so
  streaming re-scans do not spam the user.
- The FAQ now documents how to diagnose and recover from a page that only
  shows text like `<｜｜DSML｜｜>` or `antml:invoke`.

## Improvements

- The periodic protocol reminder now states two extra rules: tool calls must
  live inside a JSON code block, and platform-native syntax such as DSML/antml
  is forbidden.
- `attach_file` is now described by its delivery intent instead of as a
  fallback for `read_file`, removing the wording that nudged the model between
  the two tools.

## Engineering

- The drift notice lives in its own content module, keeping `main.ts` under the
  line limit.
- New `native_tool_syntax` unit tests cover double-bar and single-bar DSML,
  antml, ordinary prose, a valid JSON block, and empty input.
