# v1.6.1 (2026-11-02)

## Added

- `read_files` batch-read tool: reads up to 16 workspace paths in one call
  with per-file success/error envelopes; path safety is equivalent to
  `read_file`; batch risk assessment plugs into the existing approval
  fingerprint flow.
- Default rules 11-13 (zh/en prompts): prefer `;` over `&&` in compound
  commands; reuse retrieved facts instead of re-searching; reserve dry runs
  for large or destructive changes only.

## Improved

- `search_code` `path` parameter now states it accepts directories only.
- `execute_command` result payload carries the real working directory.
