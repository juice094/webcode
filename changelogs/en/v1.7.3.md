# v1.7.3 (2026-11-04)

## Fixed

- **The compressor no longer touches bootstrap tool results**: the 1.7.0
  result compression was summarizing init-phase results of bootstrap tools
  such as list_tools (the injected Available Tools list), truncating tool
  schemas and forcing the model to guess parameter names — our own
  compressor broke the "list is the single source of truth" rule.
  Bootstrap results (initialize/list_tools/list_skills/get_project_rules/
  get_project_context) are now never compressed.

## Improved

- The periodic tool-call reminder (system_note) moves from "the 5th result"
  to the last result of the current batch, restoring call-result
  correspondence inside multi-call batches.
- Prompts: serial-write rule gains a "plan multi-file work by rounds" note;
  the verification rule gains an explicit learning/demo/MVP exemption (level
  and uncovered boundaries must still be stated); built-in skill virtual
  paths are documented as directly readable via read_file; planning
  statements ("next round I will...") are explicitly not questions.
