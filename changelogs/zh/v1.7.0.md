# v1.7.0 (2026-11-03)

## 新增

- 工具结果结构化压缩器（默认 `smart` 档）：行尾空白规整、构建噪音剥
  离（`\r` 覆盖帧、进度百分比行）、连续重复行折叠（`[folded N
  identical lines]`，保留首尾行）、超限时头 50 行+省略计数+尾 20 行
  摘要。路径/哈希/错误码/堆栈帧等白名单行永不折叠。
- 设置面：`webcodeGateway.compression.toolResult`（off|trim|smart，默认
  smart）与 `webcodeGateway.compression.maxResultChars`（默认 12000，
  钳 1000–524288），VS Code 设置页即改即生效。
- 回填审计契约：压缩后的结果带 `compressed: true` 与规则命中/前后字
  符数 metadata，模型可见。
