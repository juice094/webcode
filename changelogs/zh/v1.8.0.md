# v1.8.0 (2026-11-16)

## 改进

- 初始化 payload 精简：初始化内容只保留控制流契约、项目规则和项目上下文，
  不再内嵌 `# Available Tools` / `# Available Skills` 两段 JSON 清单，
  显著缩短回填到对话框的初始化文本，适配长文本阅读限制更严的新模型。
- 工具/技能清单惰性加载：`list_tools` 与 `list_skills` 放开为模型可在会话中
  直接调用（免审批，维持原行为）；初始化回填文案与契约提示词改为引导模型
  在开始任务前先调用 `list_tools`（需要技能时再调 `list_skills`），其返回
  结果即为当前可用工具与技能的唯一事实来源。`get_project_rules` 与
  `get_project_context` 仍仅限初始化组装使用，模型直接调用会被拒，拒调文案
  不再携带产品名。
- bridge 与 gateway 版本升至 1.8.0；初始化 payload 由桥侧组装，新旧契约文本
  必须配套，故 `minExtensionVersion` 同步升至 1.8.0，旧桥接入会收到 409
  版本不匹配提示并引导升级。
