# v1.4.1 (2026-10-24)

## 修复

- 将 `zod` 升级到 4.6.7，关闭 advisory 1243066。该漏洞没有 v3 补丁版本。
  MCP SDK 声明的 peer 范围为 `^3.25 || ^4.0`，`zod-to-json-schema` 为
  `^3.25.28 || ^4`，两者都接受 v4 线；工作区现在只解析出一份 zod，
  不再保留嵌套的 v3 副本。
- 把 `body-parser` 的 override 下限提到 1.20.9，关闭 advisory 1243073。
  工作区内 express 统一解析到 1.20.9。

## 工程

- 发版构建脚本改为显式定位 Windows 自带的 bsdtar。此前从 Git Bash 环境运行时，
  PATH 可能把 Git 的 GNU tar 排在前面，而 GNU tar 会把 `C:\...` 路径里的盘符
  当作远程主机名，导致浏览器扩展打包失败。
