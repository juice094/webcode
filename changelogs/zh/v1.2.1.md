# v1.2.1 (2026-10-20)

## 功能

- 浏览器插件弹窗的授权设置从「所有工具无需审批」单开关升级为三档模式：
  始终询问 / 按需询问 / 无需审批（对齐 Kimi Code 的 Always Ask / Ask When Needed / Never Ask）。
  「按需询问」为默认档：常规工具调用自动执行，危险命令与敏感文件仍强制弹窗；
  旧版「所有工具无需审批」开关状态自动迁移为「无需审批」。会话级档位随标签页持久化，
  「新会话预设」面板可选择新建会话的默认档位。

## 安全

- 文件工具（read_file / write_file / edit_file / attach_file）新增敏感路径审批：
  访问 `.env` 系列、SSH 私钥、证书/密钥文件（.pem/.key/.ppk/.p12/.pfx/.kdbx）、
  凭证文件（credentials、.npmrc、.pypirc、.netrc 等）以及 .ssh/.aws/.gnupg/.kube 目录
  时，网关 preflight 返回待确认风险并强制弹窗，审批令牌一次性消费、两分钟过期；
  shell 路径命令（cat/cp/mv/rm 等）触及敏感文件同样触发确认。`.env.example`、公钥（*.pub）
  等模板与公开文件不误伤。
