# v1.9.1 (2026-11-24)

## 修复

- 能力快照签名生成支持 `oneOf` schema：此前 `edit_file`、`terminal_session`
  等 `oneOf` 结构工具被渲染为空括号 `()`，模型无法得知必需参数，核心写
  工具实际不可用。现渲染为「全分支必需 + 分支互斥必需（如
  `edits | patch`）+ 可选并集」，`enum` 参数附带取值
  （如 `action: list|read|stop|close`）。
- 快照附注与契约提示词声明 `list_tools` / `list_skills` 为恒可用元工具，
  不列入业务工具清单，消除与「不要假设快照之外的工具」的规则冲突；
  刷新结果覆盖内联快照，以新结果为准。
- 契约提示词补 `run_in_terminal` 闭环：调用立即返回 `session_id`
  （句柄而非结果），下一轮用 `terminal_session`（`action: "read"`）
  读取捕获输出。
- 「展示示例用文本块」规则限定为仅约束向用户讲解格式的场景；文件内的
  json 代码块为真实调用格式模板。
- 长耗时命令规则从模型自估改为显式声明：单独成批并用 `timeout` 参数
  声明预期时长（默认 60 秒，上限 1800 秒）。
- 补充环境事实：`search_files` / `search_code` 遵循 `.gitignore` 类忽略
  文件，被忽略目录静默漏掉，需改用 `execute_command`；
  `execute_command` 默认 Git Bash（POSIX）profile，其他 shell 显式传
  `profile`；`write_file` 覆盖已有文件前先 `read_file` 确认内容未被
  他人改动，新建文件无需预检。
