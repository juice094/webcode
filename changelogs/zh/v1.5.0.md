# v1.5.0 (2026-10-24)

## 新增

- 检测模型输出的平台原生工具调用语法（DeepSeek DSML、Anthropic antml）。
  命中且本轮没有可执行的 JSON 调用时，页面会弹出一致性提示，不再让整轮调用
  静默失败、只留一段无法识别的文本。同一条消息只提示一次，避免流式输出时刷屏。
- FAQ 增加「页面只出现类似 `<｜｜DSML｜｜>` 或 `antml:invoke` 的文本」的排查与恢复步骤。

## 改进

- 周期性协议提醒补充两条约束：工具调用必须放在 JSON 代码块中，禁止使用
  DSML/antml 等平台原生语法。
- `attach_file` 的描述改为按投递意图说明用途，不再写成 `read_file` 的替代方案，
  减少模型在两者之间被反向引导。

## 工程

- 协议漂移提示拆到独立的 content 模块，`main.ts` 保持在行数上限内。
- 新增 `native_tool_syntax` 单元测试，覆盖 DSML 双/单竖线、antml、普通文本、
  合法 JSON 与空输入六种输入。
