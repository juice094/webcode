# v1.7.3 (2026-11-04)

## 修复

- **压缩器不再触碰 bootstrap 工具结果**：1.7.0 引入的结果压缩会
初始化阶段的 list_tools 等引导工具结果（即注入给模型的 Available Tools
清单），导致工具 schema 被头尾摘要截断、模型只能猜参数——「列表是唯一事
实来源」规则被我们自己的压缩器打破。现在引导工具（initialize/list_tools/
list_skills/get_project_rules/get_project_context）结果永不过压缩。

  最后一个结果，不再打断多调用批次的「调用→结果」对应关系。

  传给 read_file；计划性陈述（下一轮我将…）明确不算提问。
