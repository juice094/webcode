# v1.3.0 (2026-10-21)

## 功能

- 新增统一超时设置 `webcodeGateway.timeouts`：`commandExecutionMs`、`toolCallMs`、
  `bridgeCodeTtlMs`、`approvalTtlMs`、`browserLaunchWaitMs`、`bridgeRequestMs` 全部可配，
  首尾有范围钳制，改完自动重启网关。启动日志新增 `timeouts:` 一行，列出本次实际生效的
  全部截止时间，不必再猜设置有没有被读到。
- 浏览器侧可发起配对：桥接插件弹窗可以发现本机的多个工作区网关（探测 34567-34576），
  选中后由 VS Code 侧弹出确认框；确认后才签发一次性连接码。网关为此新增未认证但收窄的
  `GET /v1/ping` 与 `POST /v1/session/request`（前者不含任何秘密，后者要求 JSON、来源白名单、
  限速窗口与人工确认四道条件同时成立）。
- 配置变更分级：工具类配置（`servers`、`skillDirectories`、`commandShell.path`、
  `command.allowedRoots`、`timeouts`）走热重载并保留桥接会话；连接身份类配置（`port`、
  `idleTimeoutMinutes`、`aiSites`、`browser`）仍走冷重启并吊销会话。
- 网关日志持久化：启动、停止、空闲自动关停、启动失败与宿主未捕获异常同步落盘到
  `globalStorage/three-water666.gateway-vscode/logs/gateway-YYYYMMDD.log`，按天滚动保留 7 天。
- 构建可自证：扩展激活时写入构建指纹行
  `build: version=… buildHash=… builtAt=… bridgeProtocol=… node=… vscode=…`；
  已认证的 `GET /v1/status` 也会返回 `version`、`buildHash`、`bridgeProtocolVersion`、`startedAt`。
- MCP 客户端握手不再固定上报 `1.0.0`，改为真实扩展版本。

## 升级注意（必读）

1. **浏览器桥必须与 VS Code 扩展同版本**。握手时浏览器侧要求
   `VS Code 扩展版本 === 浏览器扩展版本`，版本不一致会直接拒绝连接。
2. **升级后需要重启浏览器一次**。新构建会先被暂存（staged），如果隔离浏览器正在运行，
   下次点击连接时会提示“需要重启浏览器”，确认后浏览器会被关闭并重新拉起，
   之后才使用新桥接。手动加载（`chrome://extensions` → 加载已解压）的用户请先
   `pnpm bridge:sync`，再点桥接卡片的刷新按钮。
3. **升级后需要重新连接一次**。桥接会话令牌保存在网关内存中，扩展升级/重启即失效，
   请从 VS Code 状态栏重新发起连接并重新配对。自动重连会在后续版本解决。
4. 回滚：`release-archive/` 保留了上一版 vsix，`code --install-extension <旧 vsix> --force`
   即可退回。

## 修复

- 修正浏览器桥与 VS Code 扩展版本号长期不同步导致的“明明装了新版却报版本不一致”。
- 修正打包产物缺少构建标识、无法判断“装的到底是不是当前代码”的问题；
  新增发布守卫测试，三个清单版本不一致时构建期即失败。

## 重启可续（关窗/重载后自动恢复）

- 网关会话令牌改为按工作区持久化：优先存 VS Code SecretStorage（系统凭据加密，可按工作区吊销），
  不可用时降级为机器密钥派生的令牌，再退化为内存令牌（并在日志中提示）。
  窗口重载、扩展重启、网关重启后，已连接的浏览器标签使用同一个令牌自动续上，不再需要重新配对。
- `GET /v1/status` 新增 `gatewayInstanceId`（每次启动变化）与 `lastInterrupted`（上次中断的调用数量与时间）。
  兑换响应也会带上 `gatewayInstanceId`，浏览器据此区分“网关重启但令牌仍有效”与“令牌被拒绝”。
- 浏览器侧：401 先重试一次再判定失效；切回标签页时立即探测一次（不再只等 60 秒定时检查）；
  断连提示改为“正在自动恢复”，并保留重新连接的指引。
- 新增 `deactivate()` 收尾（约 300ms 硬预算、全同步）：先拒绝新请求（503），再把在途调用写入
  `globalStorage/three-water666.gateway-vscode/state/shutdown-<workspaceId>.json`，最后以
  `fast` 模式停止网关并保留会话令牌。
- 在途调用只告知、不重放：快照只保存调用名、开始时间、参数摘要（sha256）与脱敏后不超过 120 字符的预览，
  文件上限 16 KB，超过 10 分钟视为过期；重启后在日志与 `lastInterrupted` 中提示“请重试”。
- 安全边界不变：仍只监听 `127.0.0.1`，兑换仍校验来源白名单、协议版本与一次性启动码；
  想立即作废所有已连接标签页需轮换令牌（本版提供 API）。
