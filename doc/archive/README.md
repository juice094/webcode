- 结论不再有效，不得作为验收或决策依据。
- 内容不再维护，不随代码变化更新。
- 保留原因通常是记录当时的受阻状态、决策背景或失败过程。

## 判定标准

只有同时满足以下两条才归档，否则应直接删除或更新：

1. 文档结论已失效，但记录了无法从代码或提交历史还原的背景信息。
2. 存在明确的替代文档。
3. 或：文档由脚手架/生成器产出，与项目实际结构不符，直接删除会丢失“当时为何存在”的线索。

单纯的过期说明、重复内容、临时笔记不应归档。
